# トラブルシューティング

## 余白が残る・内容まで削られる

- 余白が残る場合は「許容度」を上げる。JPEG のノイズやグラデーションのある背景は、許容度 0 付近では背景とみなされない
- 内容まで削られる場合は「許容度」を下げる。背景色に近い色の内容は、許容度が高いと背景とみなされる
- 背景色が意図と違う色で検出されている場合は、スポイトやカラーピッカーで背景色を指定する ([背景色の調整](usage.md#背景色の調整))

## 背景色の自動検出が効かない

背景色を手動で指定すると、「自動」を押すまで以降の画像・一括トリミング・次回起動時にも同じ色が使われる。背景色コントロールに「手動」と表示されていれば「自動」を押して解除する。

## 「スポイト」ボタンが押せない

コンパクトモードでは元画像を表示しないため、スポイトは使えない。「⊞ 標準」で標準モードに戻す。

## 「保存」「コピー」ボタンが押せない

許容度・余白・背景色を変更した直後は、トリミングの再計算が終わるまで「💾 保存」「📋 コピー」と <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>Ctrl</kbd> + <kbd>C</kbd> が無効になる。再計算が終わると有効に戻る。

## 画像が読み込めない

- 対応していない形式は読み込めない ([対応フォーマット](formats.md#対応フォーマット))
- ファイルサイズ・幅・高さ・ピクセル数が上限を超える画像は読み込めない ([読み込み上限](formats.md#読み込み上限))。理由はステータスバーに表示される

## 一括トリミングで一部のファイルが失敗した

失敗したファイルがあっても残りの処理は続行する。ステータスバーにマウスを乗せると、失敗したファイルとエラーの詳細を確認できる。

## 保存した JPEG の透明部分が白くなる

JPEG は透明を扱えないため、透過部分を白背景に合成して保存する。透明を保つ場合は PNG / WebP / TIFF などで保存する ([出力形式](usage.md#出力形式))。

## 日本語が表示されない (Linux)

日本語のフォントが導入されていないと、文字が四角形などで表示される。Noto Sans CJK・IPA ゴシック・Takao ゴシックのいずれかを導入する (配布パッケージの標準の場所にあるものを使う)。Ubuntu / Debian の例:

```bash
sudo apt install fonts-noto-cjk
```

## 更新に失敗する (Windows)

- 確認・ダウンロードが失敗した場合は、ネットワーク接続を確認してダイアログの「再試行」でやり直す
- ダウンロードしたインストーラーのサイズ・SHA-256・署名のいずれかを検証できない場合は適用しない。時間をおいて再試行しても失敗する場合は、配布元から新しい版のインストーラーを入手して実行する
