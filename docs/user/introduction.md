# EdgeCut

画像の四辺から背景色を推定し、余白を自動で除去するデスクトップ GUI ツール。スクリーンショットの周囲余白、単色背景のイラスト、透過 PNG の外側などを、許容度と余白ピクセルを調整しながらプレビューできる。Windows 専用で、Linux / macOS には対応しない。

## はじめて使う

1. スタートメニューの **EdgeCut** から起動する
2. 「開く」で画像を選ぶか、画像をウィンドウへドラッグ & ドロップする。クリップボードの画像やコピーした画像ファイルは「貼り付け」(`Ctrl+V`) で読み込める
3. 背景色が自動で検出され、元画像 (左) とトリミング後 (右) が並んで表示される。削られる領域は元画像側で暗く表示される
4. 「許容度」「余白」のスライダーで仕上がりを調整する
5. 「保存」(`Ctrl+S`) でファイルへ書き出すか、「コピー」(`Ctrl+C`) でクリップボードへコピーする

許容度・余白・テーマ・出力形式・自動保存先などの設定は、次回起動時に自動で復元される。

## 動作環境

- Windows 10 以降 (Linux / macOS は非対応)
