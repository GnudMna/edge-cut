# 仕上がりの調整

許容度と余白だけでは思いどおりにトリミングできないときは、設定パネルの「トリミング」にある「詳細設定」と「背景色」で調整する。背景色の検出と余白の判定の仕組みは [動作の仕組み](how-it-works.md) を参照。

## トリミングの細かい調整

設定パネルの「トリミング」では、許容度と余白のほかに、辺ごとの余白と、「詳細設定」 (見出しをクリックで開閉) のノイズ除外・除去する辺・アスペクト比を指定できる。「詳細設定」を閉じていても、既定から変えている項目 (例: `ノイズ 3 px · 16:9`) を見出しの右に表示する。設定は次回起動時も保持し、保存・コピー・自動保存・一括トリミングのすべてに同じ設定が適用される。

| 項目 | 説明 |
| :--- | :--- |
| **ノイズ除外** | 背景以外の画素が指定数 (0〜50 px、既定 0) 以下の行・列を、内容とみなさずに除去する。余白内の小さなゴミ (スキャンの埃など) のせいで余白が残るときに上げる。値が大きいと細い線や小さな内容も削られる ([余白の判定](how-it-works.md#2-余白の判定)) |
| **除去する辺** | 上・右・下・左のチェックを外した辺は、元画像の端をそのまま維持する (その辺には余白も加えない)。左の図の辺をクリックしても切り替えられる。たとえば下だけ外すと、上と左右の余白だけを除去する |
| **余白 → 四辺を連動** | 「余白」の右の鎖のボタン。既定ではオン。オフにすると上・右・下・左を別々の余白 (0〜100 px) に数値で指定できる。除去しない辺の欄は無効になる |
| **アスペクト比を固定** | オンにすると、余白を加えた後の範囲を指定の比率 (幅:高さ) に合わせる。比率は 1〜9999 の整数で直接入力するか、プリセット (1:1 / 4:3 / 3:2 / 16:9 / 3:4 / 2:3 / 9:16) から選ぶ。入力欄の右の矢印のボタンで幅と高さの比を入れ替える |
| **合わせ方** | 「余白を足す」は内容を削らず、短い方の辺を背景色で塗って足す。「切り詰める」は長い方の辺を中央から削る (内容が欠ける場合がある) |

- 比率は範囲の中央を基準に合わせる。奇数ピクセルの差は、足すときは右・下へ、削るときは左・上へ多く振り分ける
- 整数ピクセルに丸めるため、実際の比率には 1 px 程度の差が出る
- 比率を合わせた結果が上限サイズ ([対応フォーマットと上限](formats.md)) を超える場合は、比率を合わせずに余白までのトリミングにとどめる
- 「切り詰める」で範囲が画像と重ならなくなる場合も、比率を合わせない
- アスペクト比の固定は、除去する辺と余白を適用した後に行う。除去しない辺は元画像の端のまま動かさず、反対側の辺だけで比率を合わせる (上下または左右の両方を除去しない場合は中央を基準にする)。結果が出力サイズの上限を超える場合などは比率を合わせず、ステータスに理由を表示する

## 背景色の調整

自動検出の結果が意図とずれる場合は、設定パネルの「トリミング」にある「背景色」で上書きできる (操作は画像を開いている間だけ表示される)。現在の背景色は色見本と 16 進数の色 (`#rrggbb`) ・アルファ値で表示され、見出しの右に自動検出中は「自動検出」、手動指定中は「手動指定」と表示される。

| 操作 | 説明 |
| :--- | :--- |
| **色見本** | 色見本をクリックして色を直接編集する。カラーピッカー・16 進数・R / G / B / A の数値で指定でき、操作を止めると反映される |
| **スポイト** | スポイトのボタンを押してから元画像をクリックし、そのピクセルの色を背景色にする。スポイト中はカーソルの位置の色と座標を表示する。プレビューが「結果」の表示のときは、元画像が見える「範囲」の表示へ切り替わる。<kbd>Esc</kbd> で解除する |
| **自動に戻す** | 円形の矢印のボタン。四辺から背景色を再検出する (手動指定を解除する。手動指定中のみ有効) |

> **注意:** 手動で指定した背景色は「自動に戻す」を押すまで解除されない。以降に開く画像・一括トリミングにもそのまま適用される。手動指定中は画面下部のステータスバーに「背景色: 手動指定」と表示され、これをクリックしても自動検出に戻せる。アプリを終了すると解除され、次回起動時は自動検出から始まる。
