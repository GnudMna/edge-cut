# 基本操作

画像を開いてトリミングし、保存・コピーするまでの操作をまとめる。仕上がりの細かい調整は [仕上がりの調整](adjust.md)、出力形式・自動保存・一括トリミングは [保存と一括処理](output.md) を参照。

## 画面構成

| 場所 | 内容 |
| :--- | :--- |
| **タイトルバー (上部)** | 左にファイル名、続けて画像の取り込み (開く・貼り付け・一括トリミング)。右に設定パネルの開閉ボタン・「≡」メニュー・ウィンドウの操作 (最小化・最大化・閉じる)。空いている部分をドラッグするとウィンドウを動かせ、ダブルクリックで最大化と元のサイズを切り替える |
| **プレビュー (中央)** | 上部の「範囲」「結果」「並べて」で表示を切り替える ([プレビューの表示](#プレビューの表示))。その右の「閉じる」で画像を閉じる。画像を開く前はドロップ領域と「画像を開く」「クリップボードから貼り付け」ボタンを表示する |
| **設定パネル (右側)** | 上端にトリミング結果と「保存」「コピー」を常に表示する。その下に「トリミング」(許容度・余白・背景色)、折りたたみできる「詳細設定」と「出力」(形式・JPEG 品質・WebP 品質・自動保存) |
| **ステータスバー (下部)** | 処理状況。一括トリミングの進捗・失敗したファイルの件数・背景色の手動指定もここに表示する。設定パネルを閉じている間は、元画像・トリミング後のサイズも表示する |

設定パネルはタイトルバーの設定パネルのボタンで開閉でき、左の境界をドラッグすると幅を変えられる (ダブルクリックで既定の幅に戻る)。開閉状態と幅は次回起動時も保持する。設定パネルを閉じている間は、「保存」「コピー」をタイトルバーに表示する。

「詳細設定」と「出力」は見出しをクリックすると開閉できる。閉じていても、見出しの右に現在の設定 (変更している詳細設定の項目・出力形式・自動保存の有無) を表示する。

設定パネル上端の結果欄には、トリミング後のサイズ・元画像に対する面積の増減・元画像のサイズ・トリミング範囲の左上の位置を表示する。設定の変更後、再計算が終わるまではサイズを薄く表示し、「計算中」と表示する。

ウィンドウの位置と大きさ (最大化していたか) は次回起動時に復元する。

## 基本的な流れ

| ステップ | 操作 | 説明 |
| :--- | :--- | :--- |
| **1** | **画像を開く** | 「開く」でファイルを選択、ウィンドウへドラッグ & ドロップ、または「貼り付け」でクリップボードから読み込む (クリップボードの画像のほか、エクスプローラーなどでコピーした画像ファイルも貼り付けられる) |
| **2** | **許容度を調整** | 設定パネルの「許容度」スライダーで背景色の許容範囲を設定する (0: 完全一致に近い、100: 広い範囲を余白とみなす) |
| **3** | **余白を調整** | 設定パネルの「余白」で、トリミング後に追加したい余白ピクセル数を設定する (0〜100 px)。内容から四辺までが常に指定幅になり、元画像の端を越える分は背景色で塗られる。辺ごとの指定は [トリミングの細かい調整](adjust.md#トリミングの細かい調整) を参照 |
| **4** | **結果を出力** | 設定パネル下端の「保存」でファイルへ書き出す、または「コピー」でクリップボードへコピーする。設定変更後のトリミング再計算中は両ボタンが無効になる。保存する形式とファイル名は [保存と一括処理](output.md) を参照 |

スライダーはドラッグ中もプレビューが更新される。スライダーの右の欄には数値を直接入力でき (<kbd>Enter</kbd> で確定)、欄で <kbd>↑</kbd> <kbd>↓</kbd> を押すと 1 ずつ (<kbd>Shift</kbd> を押しながらで 10 ずつ) 変えられる。スライダーをクリックしてから <kbd>←</kbd> <kbd>→</kbd> キーを押しても値を微調整できる。

### プレビューの表示

プレビュー上部の切り替えで、表示を次の 3 つから選ぶ。選んだ表示は次回起動時も保持する。

| 表示 | 説明 |
| :--- | :--- |
| **範囲** (既定) | 元画像を大きく表示し、削られる領域を暗くしてトリミング範囲の枠線を重ねる |
| **結果** | トリミング後の画像だけを表示する |
| **並べて** | 元画像 (左) とトリミング後 (右) を並べて表示する |

透明部分は市松模様で表示する。「範囲」では削られる領域を暗くし、トリミング範囲を枠と四隅の印で示す。「結果」の表示中にスポイトのボタンを押すと、元画像をクリックできるよう「範囲」の表示へ切り替わる。

### ズームとパン

プレビューは各ペイン (元画像・トリミング後) を個別に拡大・縮小できる。倍率と位置は表示を切り替えても保持する。画像がペインより大きいときは、ペインに収まる倍率で表示する。

| 操作 | 説明 |
| :--- | :--- |
| **ホイール** | カーソル位置を中心に拡大・縮小する (最大 1600%)。収まる倍率より小さくはならない |
| **ドラッグ** | 拡大した画像を移動する |
| **− / +** | 縮小・拡大する |
| **フィット** (四隅の印のボタン、または倍率の表示をクリック) | ペインに収まる倍率へ戻す。ウィンドウサイズの変更にも追従する |
| **1:1** | 等倍 (画像 1 px を画面の物理 1 px) で表示する。表示スケールが 125% などの環境でも画素がそろって表示される |
| **ダブルクリック** | フィットのときは等倍に、それ以外はフィットに切り替える |

ズームの操作と現在の倍率はペインの右下に表示する。新しい画像を開くと、倍率と位置は元に戻る。

## その他の操作

| ボタン | 説明 |
| :--- | :--- |
| 閉じる (プレビュー上部) | 読み込んだ画像を閉じて初期状態に戻す |
| 設定パネルのボタン (タイトルバー右) | 右側の設定パネルを開閉する |
| ≡ (タイトルバー右) | メニューを開く。次の項目がある |

「≡」メニューの項目は次のとおり。

| 項目 | 説明 |
| :--- | :--- |
| テーマ (システムに合わせる / ライト / ダーク) | 配色の切り替え。「システムに合わせる」は Windows の設定 (アプリ モード) に従う |
| ドキュメント | このドキュメントを既定のブラウザで開く |
| ライセンス | このアプリのライセンスをメモ帳で開く |
| 第三者ライセンス | 使用しているオープンソースソフトウェアのライセンスをメモ帳で開く |
| 更新を確認… | 更新ダイアログを開く。右に現在のバージョンを表示する |

## キーボードショートカット

各ボタンにマウスを乗せたときの表示にも対応するキーを記載している。

| キー | 操作 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | 画像を開く |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | 一括トリミング |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | クリップボードから貼り付け |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | トリミング後の画像を保存 |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | トリミング後の画像をコピー |
| <kbd>Delete</kbd> | 画像を閉じる |
| <kbd>Esc</kbd> | スポイトを解除 (スポイト中でなければ一括トリミングを中止) |

## アプリ更新

タイトルバー右の「≡」メニューから現在のバージョンを確認し、更新を適用できる。インストーラーの操作は要らない。

1. 「更新を確認…」で更新ダイアログを開き、GitHub の最新リリースを問い合わせる
2. 新しいバージョンがあれば、現在・最新のバージョンとサイズが表示される。「更新する」で「EdgeCut の更新」画面 (更新プログラム) が開く
3. 更新画面で「更新する」を押すと、更新ファイルをダウンロードする。ダウンロード中も EdgeCut は使え、更新画面の「中止」でやめられる。ダウンロード中に EdgeCut を閉じた場合は、更新だけ行って起動はしない (更新画面の「EdgeCut を起動」で起動できる)
4. サイズ・SHA-256・署名をすべて検証できたら EdgeCut を終了し (保存中の画像があれば完了を待つ)、新しい版をインストールして起動し直す。未保存の画像は先に保存しておく

ポータブル版は、実行フォルダのファイルを新しい版に差し替える。`data` フォルダ (設定など) はそのまま残る。

一括トリミングや保存の実行中は「更新する」を押せない。完了してから更新する。

最新版を使用している場合は「再確認」で問い合わせ直せる。確認・ダウンロードにはタイムアウトがあり、失敗時はダイアログの「再試行」でやり直せる。検証に失敗した更新ファイルは適用しない。インストールに失敗した場合は、更新画面の「EdgeCut を起動」で元の版を起動できる。
