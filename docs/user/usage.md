# 使い方

## 画面構成

| 場所 | 内容 |
| :--- | :--- |
| **ツールバー (上部)** | 画像の取り込み (開く・貼り付け・一括トリミング)、結果の出力 (保存・コピー)、クリア。右端に「⚙ 設定」(設定パネルの開閉) と「☰」メニュー |
| **プレビュー (中央)** | 元画像とトリミング後の画像 |
| **設定パネル (右側)** | 「トリミング」(許容度・余白)、「背景色」、「出力」(形式・JPEG 品質・自動保存) |
| **ステータスバー (下部)** | 処理状況と、元画像・トリミング後のサイズ |

設定パネルは「⚙ 設定」で開閉でき、境界をドラッグすると幅を変えられる。開閉状態は次回起動時も保持する。

## 基本的な流れ

| ステップ | 操作 | 説明 |
| :--- | :--- | :--- |
| **1** | **画像を開く** | 「📂 開く」でファイルを選択、ウィンドウへドラッグ & ドロップ、または「📥 貼り付け」でクリップボードから読み込む (クリップボードの画像のほか、エクスプローラーなどでコピーした画像ファイルも貼り付けられる) |
| **2** | **許容度を調整** | 設定パネルの「許容度」スライダーで背景色の許容範囲を設定する (0: 完全一致に近い、100: 広い範囲を余白とみなす) |
| **3** | **余白を調整** | 設定パネルの「余白」で、トリミング後に追加したい余白ピクセル数を設定する (0〜100 px)。内容から四辺までが常に指定幅になり、元画像の端を越える分は背景色で塗られる |
| **4** | **結果を出力** | 「💾 保存」でファイルへ書き出す、または「📋 コピー」でクリップボードへコピーする。設定変更後のトリミング再計算中は両ボタンが無効になる |

スライダーはドラッグ中もプレビューが更新される。スライダーにマウスを乗せた状態で <kbd>←</kbd> <kbd>→</kbd> キーを押すと値を微調整できる。

プレビューは元画像 (左) とトリミング後 (右) を並べて表示する。元画像側は削られる領域を暗くし、トリミング範囲の枠線を重ねる。透明部分は市松模様で表示する。

## 背景色の調整

自動検出の結果が意図とずれる場合は、設定パネルの「背景色」で上書きできる (画像を開いている間だけ表示される)。現在の背景色は色見本と `RGBA(r, g, b, a)` で表示され、自動検出中は「自動検出」、手動指定中は「手動指定」と表示される。

| 操作 | 説明 |
| :--- | :--- |
| **色見本** | 色見本をクリックして RGBA を直接編集する |
| **💧 スポイト** | 「💧 スポイト」を押してから元画像をクリックし、そのピクセルの色を背景色にする (コンパクト表示では使えない) |
| **↺ 自動に戻す** | 四辺から背景色を再検出する (手動指定を解除する。手動指定中のみ有効) |

> **注意:** 手動で指定した背景色は「↺ 自動に戻す」を押すまで解除されない。以降に開く画像・一括トリミング・次回起動時にもそのまま適用される。

## 自動保存

設定パネルの「出力」で「自動保存」を有効にすると、画像を開いた直後にトリミング結果を保存する。「保存先」の「📁 変更…」で保存先フォルダを指定できる (現在の保存先はその下に表示される)。トリミングの再計算中に有効にした場合は、再計算の完了後に保存する。

- 出力ファイル名は `{元ファイル名}_trimmed.{拡張子}` (クリップボードから貼り付けた画像は `clipboard_trimmed.{拡張子}`)
- 拡張子は「形式」の設定に従う ([出力形式](#出力形式) を参照)
- 同名ファイルがある場合は上書きせず `_2`, `_3`, ... と連番を付ける
- 直前と同じ画像・トリミング範囲・出力形式・保存先の場合は再保存しない (チェックの OFF → ON を繰り返しても連番ファイルは増えない)

既定の保存先は、OS のピクチャフォルダ内の `EdgeCut` フォルダ。

| プラットフォーム | 既定の保存先 |
| :--- | :--- |
| Windows | ピクチャフォルダ (OneDrive へ移動している場合はその場所) 内の `EdgeCut` |
| Linux | XDG のピクチャフォルダ (日本語環境では `~/画像` など) 内の `EdgeCut`。設定がなければ `~/Pictures/EdgeCut` |
| macOS | `~/Pictures/EdgeCut` |

保存先を一度変更した場合は、次回起動時もその設定を使う。

## 一括トリミング

「✂ 一括トリミング…」から複数の画像ファイルと出力フォルダを選択すると、現在の許容度・余白・背景色の設定でまとめて処理する。

- 出力ファイル名は `{元ファイル名}_trimmed.{拡張子}`
- 拡張子は「形式」の設定に従う ([出力形式](#出力形式) を参照)
- 同名ファイルがある場合は上書きせず `_2`, `_3`, ... と連番を付ける
- 複数の画像ファイルをウィンドウへドラッグ & ドロップした場合も、出力フォルダを選択して一括トリミングを開始する (未対応の拡張子は除外し、除外件数をステータスバーに表示する)
- エクスプローラーなどでコピーしたファイル・フォルダを「📥 貼り付け」(`Ctrl+V`) した場合も、ドラッグ & ドロップと同じ規則で処理する
- フォルダをドラッグ & ドロップした場合は、フォルダ直下の対応画像を一括トリミングする (サブフォルダは対象外。対象が 1 件でも一括トリミングとして処理する)
- 処理はバックグラウンドで最大 4 ファイル (CPU コア数が少ない場合はコア数まで) を並列に実行し、進捗はステータスバーに表示する
- 処理中は「✂ 一括トリミング…」の位置に表示される「⏹ キャンセル」(<kbd>Esc</kbd>) で中止できる。処理中のファイルは完了させ、未着手のファイルは処理しない
- 失敗したファイルがあっても残りの処理は続行する。完了時にエラー一覧のウィンドウを開き、失敗したファイルとエラーの詳細を入力順に表示する。「すべてコピー」でクリップボードへコピーできる。閉じた後は、ステータスバーの「エラー一覧」ボタンから再度開ける

## 出力形式

設定パネルの「出力」→「形式」で、保存・自動保存・一括トリミングの出力形式をまとめて指定できる (設定は次回起動時も保持する)。

| 選択 | 出力 |
| :--- | :--- |
| 元の形式 (既定) | 元画像の拡張子を維持する (小文字化)。拡張子がない・未対応の場合とクリップボードから貼り付けた画像は PNG |
| PNG / JPEG / WebP / BMP / TIFF / GIF | 指定した形式 (`.png` / `.jpg` / `.webp` / `.bmp` / `.tiff` / `.gif`) |

- 「💾 保存」ではダイアログの既定のファイル名・種類に反映される。ダイアログで別の拡張子を入力した場合はその形式で保存し、拡張子を省略した場合は設定の形式で保存する
- 「形式」が「元の形式」または「JPEG」のときは「JPEG 品質」(1-100、既定 95) を指定できる。値が大きいほど高画質でファイルサイズも大きくなる (設定は次回起動時も保持する)
- 形式ごとの変換 (JPEG の透過部分の扱いなど) は [対応フォーマットと上限](formats.md) を参照

## その他の操作

| ボタン | 説明 |
| :--- | :--- |
| 🗑 クリア | 読み込んだ画像をクリアして初期状態に戻す |
| ⚙ 設定 | 右側の設定パネルを開閉する |
| ☰ | メニューを開く。次の項目がある |

「☰」メニューの項目は次のとおり。

| 項目 | 説明 |
| :--- | :--- |
| 🌙 ダークテーマ / ☀ ライトテーマ | テーマの切り替え |
| コンパクト表示 | チェックすると、プレビューにトリミング後の画像だけを表示する |
| バージョン | 現在のバージョンを表示する |
| 更新を確認… | 更新ダイアログを開く (Windows のみ) |

## キーボードショートカット

macOS では <kbd>Ctrl</kbd> の代わりに <kbd>⌘</kbd> を使う。各ボタンにマウスを乗せたときの表示にも対応するキーを記載している。

| キー | 操作 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | 画像を開く |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | 一括トリミング |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | クリップボードから貼り付け |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | トリミング後の画像を保存 |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | トリミング後の画像をコピー |
| <kbd>Delete</kbd> | 画像をクリア |
| <kbd>Esc</kbd> | スポイトを解除 (スポイト中でなければ一括トリミングを中止) |

## アプリ更新 (Windows)

ツールバー右端の「☰」メニューから現在のバージョンを確認し、更新を適用できる。

1. 「更新を確認…」で更新ダイアログを開き、最新リリースを問い合わせる
2. 新しいバージョンがあれば、現在・最新のバージョンとサイズが表示される。「⬇ ダウンロードしてインストール」でインストーラー (MSI) をダウンロードする
3. サイズ・SHA-256・署名をすべて検証できた場合のみインストーラーを起動し、EdgeCut は終了する (未保存の画像は先に保存しておく)

確認・ダウンロードにはタイムアウトがあり、失敗時はダイアログの「再試行」でやり直せる。検証に失敗したインストーラーは適用しない。

Linux / macOS 版には「更新を確認…」と更新機能がない。新しい版の配布物を入手して入れ替える。
