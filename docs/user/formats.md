# 対応フォーマットと上限

## 対応フォーマット

読み込み・保存ともに次の形式に対応する。

| 形式 | 拡張子 |
| :--- | :--- |
| PNG | `.png` |
| JPEG | `.jpg` / `.jpeg` |
| BMP | `.bmp` |
| GIF | `.gif` |
| TIFF | `.tiff` / `.tif` |
| WebP | `.webp` |

保存する形式はツールバーの「形式」で選ぶ ([出力形式](usage.md#出力形式))。

## 保存時の変換

- **JPEG:** 透過部分を白背景に合成し、「JPEG 品質」の設定 (既定 95) で保存する。グレースケール画像はグレースケールのまま保存する
- **WebP:** ロスレスで保存する。品質は選べない
- **GIF:** 256 色以下に減色して保存する。ディザリングは行わないため、グラデーションや写真では色の段差が目立つことがある。透過は 1 bit のため、半透明の部分は完全な透明か不透明のどちらかになる。画質を保ちたい場合や半透明を保つ場合は PNG / WebP / TIFF で保存する
- **PNG / TIFF 以外:** 16bit 画像を 8bit に変換して保存する

## 色と向きの扱い

- **EXIF の回転情報:** スマートフォンの写真などに含まれる向きの情報 (回転・反転) を、読み込み時に画像へ反映する
- **ICC プロファイル:** 元画像に埋め込まれた ICC プロファイルを、PNG / JPEG / TIFF / WebP で保存する場合に再び埋め込み、色の見え方を保つ。BMP / GIF は ICC プロファイルに対応しないため埋め込まない。CMYK の JPEG など、出力画像と色空間が合わないプロファイルも埋め込まない

## 引き継がない情報

保存した画像には、元画像のメタデータのうち上記の ICC プロファイルだけを引き継ぐ。それ以外は出力に残らない。

- **EXIF・XMP など:** 撮影日時、撮影機器、GPS の位置情報、著作権表記、コメントなどは保存した画像に含まれない。回転情報も画像に反映済みのため、出力には向きのタグを書き込まない
- **アニメーション:** アニメーション GIF / WebP は先頭の 1 フレームだけを読み込む。トリミングも保存もその 1 フレームに対して行い、保存した画像は静止画になる

位置情報などを含む写真を共有する前に、メタデータを取り除く用途にも使える。

## 読み込み上限

大きすぎる画像でメモリが足りなくなるのを防ぐため、次の上限がある。

| 項目 | 上限 |
| ---- | :--: |
| ファイルサイズ | 256 MB |
| 幅・高さ | 各 16,384 px |
| ピクセル数 | 約 6,400 万 (8,000 × 8,000 相当) |

- 上限を超えるファイルは読み込み時にエラーとなり、ステータスバーに理由が表示される
- クリップボードから貼り付けた画像にも、同じ幅・高さ・ピクセル数の上限を適用する
- プレビューでは長辺 4,096 px を超える画像を縮小して表示するが、保存・コピーは元の解像度で行う
