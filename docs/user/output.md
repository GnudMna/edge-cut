# 保存と一括処理

トリミング結果の出力形式とファイル名、画像を開いた直後の自動保存、複数ファイルの一括トリミングをまとめる。形式ごとの変換 (JPEG の透過部分の扱いなど) は [対応フォーマットと上限](formats.md) を参照。

## 出力形式

設定パネルの「出力」→「形式」で、保存・自動保存・一括トリミングの出力形式をまとめて指定できる (設定は次回起動時も保持する)。

| 選択 | 出力 |
| :--- | :--- |
| 元の形式 (既定) | 元画像の形式を維持する。形式はファイルの中身で判定し、拡張子と食い違う場合 (中身が PNG の `.jpg` など) は中身の形式で保存する。一致する場合は元の拡張子を小文字にして使う。判定できず拡張子もない・未対応の場合とクリップボードから貼り付けた画像は PNG |
| PNG / JPEG / WebP / BMP / TIFF / GIF | 指定した形式 (`.png` / `.jpg` / `.webp` / `.bmp` / `.tiff` / `.gif`) |

- 「保存」ではダイアログの既定のファイル名・種類に反映される。ダイアログで対応形式の別の拡張子を入力した場合はその形式で保存する。対応形式の拡張子で終わらない名前 (`image v1.2` など) には、設定の形式の拡張子を末尾に補って保存する
- 「形式」が「元の形式」または「JPEG」のときは「JPEG 品質」(1-100、既定 95) を指定できる。値が大きいほど高画質でファイルサイズも大きくなる (設定は次回起動時も保持する)
- 「形式」が「元の形式」または「WebP」のときは「WebP 品質」(1-100、既定 90) を指定できる。値が大きいほど高画質でファイルサイズも大きくなり、100 のときだけロスレスで保存する (設定は次回起動時も保持する)

## 出力ファイル名

「保存」ダイアログの既定のファイル名と、自動保存・一括トリミングで書き出すファイル名は、次の規則で決まる。

- `{元ファイル名}_trimmed.{拡張子}`。クリップボードから貼り付けた画像は `clipboard_trimmed.{拡張子}`
- 拡張子は「形式」の設定に従う ([出力形式](#出力形式))
- 自動保存と一括トリミングでは、同名ファイルがある場合は上書きせず `_2`, `_3`, ... と連番を付ける

## 自動保存

設定パネルの「出力」で「自動保存」を有効にすると、画像を開いた直後にトリミング結果を保存する。「保存先」の「変更…」で保存先フォルダを指定できる (現在の保存先はその下に表示される)。トリミングの再計算中に有効にした場合は、再計算の完了後に保存する。ファイル名は [出力ファイル名](#出力ファイル名) の規則で決まる。

- 直前と同じ画像・トリミング範囲・出力形式・保存先の場合は再保存しない (チェックの OFF → ON を繰り返しても連番ファイルは増えない)
- 既定の保存先は、ピクチャフォルダ (OneDrive へ移動している場合はその場所) 内の `EdgeCut` フォルダ
- 保存先を一度変更した場合は、次回起動時もその設定を使う

## 一括トリミング

「一括トリミング…」から複数の画像ファイルと出力フォルダを選択すると、現在のトリミング設定 (許容度・ノイズ除外・除去する辺・余白・アスペクト比) と背景色でまとめて処理する。ファイル名は [出力ファイル名](#出力ファイル名) の規則で決まる。

- 複数の画像ファイルをウィンドウへドラッグ & ドロップした場合も、出力フォルダを選択して一括トリミングを開始する (未対応の拡張子は除外し、除外件数をステータスバーに表示する)
- エクスプローラーなどでコピーしたファイル・フォルダを「貼り付け」(`Ctrl+V`) した場合も、ドラッグ & ドロップと同じ規則で処理する
- フォルダをドラッグ & ドロップした場合は、フォルダ直下の対応画像を一括トリミングする (サブフォルダは対象外。対象が 1 件でも一括トリミングとして処理する)。ネットワークドライブやファイルの多いフォルダでは確認に時間がかかることがあり、その間はステータスバーに「ドロップされたファイルを確認中...」と表示される
- 処理はバックグラウンドで最大 4 ファイル (CPU コア数が少ない場合はコア数まで) を並列に実行し、進捗はステータスバーに表示する。大きな画像が重なる場合はメモリ不足を避けるため並列数を自動で減らす
- 処理中は「一括トリミング…」の位置に表示される「キャンセル」(<kbd>Esc</kbd>) で中止できる。処理中のファイルは完了させ、未着手のファイルは処理しない
- 処理中にウィンドウを閉じようとすると確認ダイアログが開く。「中止して終了」を選ぶと、処理中のファイルの保存を終えてから終了する (ウィンドウはすぐに消える)。「続ける」を選ぶと処理を続行する
- 失敗したファイルがあっても残りの処理は続行する。完了時にエラー一覧のウィンドウを開き、失敗したファイルとエラーの詳細を入力順に表示する。「すべてコピー」でクリップボードへコピーできる。閉じた後は、ステータスバーの「エラー一覧」ボタンから再度開ける
