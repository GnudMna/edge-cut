# トラブルシューティング

## 余白が残る・内容まで削られる

- 余白が残る場合は「許容度」を上げる。JPEG のノイズやグラデーションのある背景は、許容度 0 付近では背景とみなされない
- 余白内の小さなゴミ (スキャンの埃など) でトリミングされない場合は、「ノイズ除外」を上げる。行・列あたりの画素数が指定以下のゴミを無視する
- 内容まで削られる場合は「許容度」を下げる。背景色に近い色の内容は、許容度が高いと背景とみなされる
- 端にある細い線や小さな内容が削られる場合は「ノイズ除外」を下げる (0 にすると 1 画素でも内容として残す)
- 背景色が意図と違う色で検出されている場合は、スポイトやカラーピッカーで背景色を指定する ([背景色の調整](adjust.md#背景色の調整))

## 背景色の自動検出が効かない

背景色を手動で指定すると、「自動に戻す」を押すかアプリを終了するまで、以降の画像・一括トリミングにも同じ色が使われる。ステータスバーに「背景色: 手動指定」と表示されていれば「自動に戻す」を押して解除する ([背景色の調整](adjust.md#背景色の調整))。

## 「保存」「コピー」ボタンが押せない

トリミングの設定 (許容度・ノイズ除外・余白など) や背景色を変更した直後は、トリミングの再計算が終わるまで「保存」「コピー」と <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>Ctrl</kbd> + <kbd>C</kbd> が無効になる。再計算が終わると有効に戻る。

## 画像が読み込めない

- 対応していない形式は読み込めない ([対応フォーマット](formats.md#対応フォーマット))
- ファイルサイズ・幅・高さ・ピクセル数が上限を超える画像は読み込めない ([読み込み上限](formats.md#読み込み上限))。理由はステータスバーに表示される

## 一括トリミングで一部のファイルが失敗した

失敗したファイルがあっても残りの処理は続行する。完了時に開くエラー一覧のウィンドウで、失敗したファイルとエラーの詳細を確認できる。閉じた後は、ステータスバーの「エラー N 件」から再度開ける。

## 起動できない (WebView2 ランタイム)

EdgeCut の画面の表示には Microsoft Edge WebView2 ランタイムを使う。Windows 11 には標準で入っているが、Windows 10 の一部の環境には入っていない。「EdgeCut を起動できませんでした」と表示される場合は、Microsoft の配布ページから WebView2 ランタイム (Evergreen) を導入してから起動し直す。

## 「予期しないエラーが発生した」と表示されて終了した

アプリの不具合で終了するときに表示される。詳細は `%LOCALAPPDATA%\EdgeCut\panic.log` (ポータブル版は実行フォルダの `data\panic.log`) に追記されるため、不具合を報告するときはこのファイルを添付する。ファイルが 256 KiB を超えると、古い記録は同じフォルダーの `panic.log.1` に移され、さらに古いものは削除される。直前の記録が見当たらないときは `panic.log.1` も確認する。

## 保存した JPEG の透明部分が白くなる

JPEG は透明を扱えないため、透過部分を白背景に合成して保存する。透明を保つ場合は PNG / WebP / TIFF などで保存する ([出力形式](output.md#出力形式))。

## 更新に失敗する

- 確認・ダウンロードが失敗した場合は、ネットワーク接続を確認してダイアログの「再試行」でやり直す
- プロキシやファイアウォールで接続先を制限している場合は、`api.github.com`・`github.com`・`release-assets.githubusercontent.com` を許可する
- 「更新情報の取得が拒否されました」と表示された場合は、GitHub が同じ接続元からの照会回数を制限している。社内ネットワークなどで接続元を共有していると、ほかの利用者の照会も数えられる。時間をおいてやり直す
- ダウンロードした更新ファイルのサイズ・SHA-256・署名のいずれかを検証できない場合は適用しない。時間をおいて再試行しても失敗する場合は、配布元から新しい版のインストーラー (ポータブル版は ZIP) を入手する
- 「インストールした場所 (bin フォルダ) の EdgeCut ではない」と表示された場合は、インストール先から別の場所へコピーした `EdgeCut.exe` を起動している。スタートメニューの **EdgeCut** から起動して更新する
- 「更新プログラム (EdgeCutUpdater.exe) が見つかりません」と表示された場合は、配布物のファイルが欠けている。インストーラーを実行し直す (ポータブル版は ZIP を展開し直し、`data` フォルダを移す)
- インストールに失敗した場合は、更新画面に表示される詳細ログ (`%LOCALAPPDATA%\EdgeCut\logs\updater-msi.log`) に原因が記録されている。更新画面の「EdgeCut を起動」で元の版を使い続けられる
- 「別のインストールが進行中です」と表示された場合は、Windows Update などのインストールが終わってから更新し直す
- 「Windows の再起動が必要です」と表示された場合は、Windows を再起動すると更新が完了する
- ポータブル版でファイルの差し替えに失敗した場合は、更新前のファイルへ戻す。エクスプローラーなどで実行フォルダのファイルを開いていないか確認してやり直す
