# 動作の仕組み

EdgeCut は次の 3 段階で余白を除去する。操作は [トリミングの細かい調整](adjust.md#トリミングの細かい調整) を参照。

## 1. 背景色の検出

画像の上・下・左・右の全辺のピクセルを走査し、量子化した色の近傍で最も票の多いまとまりから、最も多く現れる RGBA 値を背景色とする。JPEG のノイズなどで同系色の票が割れても安定して検出でき、角が丸い素材や隅に異なる色がある画像でも誤検出しにくい。

背景色は自動検出のほか、カラーピッカーでの手動指定や元画像のスポイトでも上書きできる ([背景色の調整](adjust.md#背景色の調整))。

## 2. 余白の判定

各ピクセルと背景色の RGBA の距離が「許容度」以内なら背景とみなす。

- 許容度 N のしきい値は、RGB の最大距離 (黒〜白、約 441.7) の N%。0 は完全一致、100 はすべてのピクセルを背景とする
- アルファ (不透明度) の差も距離に含めるため、不透明な背景上の半透明ピクセルは内容として残る
- アルファ値が 16 未満のほぼ完全に透明なピクセルは、常に背景として扱う
- 背景が透明な場合は RGB を見ず、アルファの差だけで判定する。許容度 N なら、背景とのアルファ差が 255 の N% 以内の画素を背景とみなす (半透明の影やアンチエイリアスのにじみを許容度で削れる)

背景以外の画素が「ノイズ除外」で指定した数以下の行・列は、内容とみなさない。スキャンの埃や JPEG ノイズのような孤立した小さなゴミで余白が残るのを防げる。0 のときは 1 画素でも内容とする。内容の行・列にも同じ基準が働くため、細い線や小さな内容は指定数が大きいと削られる。

## 3. トリミング

上下左右から背景と判定された領域を除去し、四辺へ指定ピクセル数の余白を追加する。余白は四辺共通のほか、辺ごとに別々の値を指定できる。除去しない辺を選んだ場合、その辺は元画像の端を維持し、余白も加えない。

余白が元画像の端を越える場合は、越えた分を背景色で塗って追加する。背景が透明な場合、追加する余白は完全に透明になる。

アスペクト比を固定した場合は、余白を加えた後の範囲を最後に指定の比率へ合わせる。「余白を足す」は短い方の辺を背景色で塗って足し、「切り詰める」は長い方の辺を削る。いずれも範囲の中央を基準にする。背景しかない画像も、同じ比率に合わせる。
