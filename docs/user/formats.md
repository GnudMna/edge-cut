# 対応フォーマットと上限

## 対応フォーマット

読み込み・保存ともに次の形式に対応する。

| 形式 | 拡張子 |
| :--- | :--- |
| PNG | `.png` |
| JPEG | `.jpg` / `.jpeg` |
| BMP | `.bmp` |
| GIF | `.gif` |
| TIFF | `.tiff` / `.tif` |
| WebP | `.webp` |

保存する形式は設定パネルの「出力」→「形式」で選ぶ ([出力形式](output.md#出力形式))。

## 保存時の変換

- **JPEG:** 透過部分を白背景に合成し、「JPEG 品質」の設定 (既定 95) で保存する。グレースケール画像はグレースケールのまま保存する
- **WebP:** 「WebP 品質」の設定 (既定 90) で保存する。100 のときだけロスレスで保存し、それ未満はロッシー (非可逆) で保存する
- **GIF:** 256 色以下に減色して保存する。ディザリングは行わないため、グラデーションや写真では色の段差が目立つことがある。透過は 1 bit のため、半透明の部分は完全な透明か不透明のどちらかになる。画質を保ちたい場合や半透明を保つ場合は PNG / WebP / TIFF で保存する
- **PNG / TIFF 以外:** 16bit 画像を 8bit に変換して保存する

## 色と向きの扱い

- **EXIF の回転情報:** スマートフォンの写真などに含まれる向きの情報 (回転・反転) を、読み込み時に画像へ反映する
- **ICC プロファイル:** 元画像に埋め込まれた ICC プロファイルを、PNG / JPEG / TIFF / WebP で保存する場合に再び埋め込み、色の見え方を保つ。BMP / GIF は ICC プロファイルに対応しないため埋め込まない。CMYK の JPEG など、出力画像と色空間が合わないプロファイルも埋め込まない。グレースケール + 透過の画像は、JPEG 以外では RGBA に変換して保存するため、GRAY のプロファイルは埋め込まない (TIFF は GRAY + 透過の形式で保存できない)。16 MiB を超えるプロファイルは無いものとして読み込み、保存時にも埋め込まない
- **解像度 (DPI):** 元画像に記録された解像度を、PNG / JPEG / TIFF で保存する場合に書き込み、300 dpi のスキャン画像などの印刷サイズが変わらないようにする。縦横で値が違う場合もそのまま引き継ぎ、EXIF の回転情報で向きが変わるときは縦横を入れ替える。WebP / BMP / GIF は書き込まない。縦横比だけを表す記録など、長さの単位でない解像度は無いものとして扱う
- **プレビューの色:** RGB / GRAY の ICC プロファイルは sRGB に変換して表示するため、広色域やガンマの異なるグレースケールの画像も実際の見え方に近い色で確認できる。保存する画像のピクセル値は変換しない。プロファイルが無い画像は sRGB として表示する
- **コピー:** クリップボードには ICC プロファイルを載せられないため、RGB / GRAY のプロファイルを持つ画像は sRGB へ変換してからコピーし、貼り付け先でもプレビューと同じ色に見えるようにする。解像度 (DPI) やその他のメタデータもクリップボードには載らない。元の色空間やプロファイルを保ちたい場合は「保存」を使う

## 引き継がない情報

保存した画像には、元画像のメタデータのうち上記の ICC プロファイルと解像度だけを引き継ぐ。それ以外は出力に残らない。

- **EXIF・XMP など:** 撮影日時、撮影機器、GPS の位置情報、著作権表記、コメントなどは保存した画像に含まれない。回転情報も画像に反映済みのため、出力には向きのタグを書き込まない
- **アニメーション・複数ページ:** アニメーション GIF / WebP / APNG と複数ページの TIFF は、先頭の 1 フレーム (ページ) だけを読み込む。トリミングも保存もその 1 フレームに対して行い、保存した画像は 1 枚だけの静止画になる。1 枚ずつ開いたときは、ステータスバーに「先頭の 1 フレームのみ読み込み」と表示される。複数ファイルやフォルダの一括トリミングでは、この表示は出ない

位置情報などを含む写真を共有する前に、メタデータを取り除く用途にも使える。

## 読み込み上限

大きすぎる画像でメモリが足りなくなるのを防ぐため、次の上限がある。

| 項目 | 上限 |
| :--- | :--- |
| ファイルサイズ | 256 MiB |
| 幅・高さ | 各 16,384 px |
| ピクセル数 | 約 6,400 万 (8,000 × 8,000 相当) |

- 上限を超えるファイルは読み込み時にエラーとなり、ステータスバーに理由が表示される
- クリップボードから貼り付けた画像にも、同じ幅・高さ・ピクセル数の上限を適用する
- プレビューでは長辺 4,096 px を超える画像を縮小して表示するが、保存・コピーは元の解像度で行う (縮小表示した画像を拡大すると、縮小後の解像度で表示される)
