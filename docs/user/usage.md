# 基本操作

画像を開いてトリミングし、保存・コピーするまでの操作をまとめる。仕上がりの細かい調整は [仕上がりの調整](adjust.md)、出力形式・自動保存・一括トリミングは [保存と一括処理](output.md) を参照。

## 画面構成

| 場所 | 内容 |
| :--- | :--- |
| **ツールバー (上部)** | 画像の取り込み (開く・貼り付け・一括トリミング)。右端に「設定」(設定パネルの開閉) と「≡」メニュー |
| **プレビュー (中央)** | 上部の「範囲」「結果」「並べて」で表示を切り替える ([プレビューの表示](#プレビューの表示))。右上の「クリア」で画像を閉じる。画像を開く前はドロップ領域と「画像を開く」「クリップボードから貼り付け」ボタンを表示する |
| **設定パネル (右側)** | 「トリミング」(許容度・余白・背景色と、折りたたんだ「詳細設定」)、「出力」(形式・JPEG 品質・WebP 品質・自動保存)。下端にトリミング後のサイズと「保存」「コピー」を常に表示する |
| **ステータスバー (下部)** | 処理状況。設定パネルを閉じている間は、元画像・トリミング後のサイズもここに表示する |

設定パネルは「設定」で開閉でき、境界をドラッグすると幅を変えられる。開閉状態は次回起動時も保持する。設定パネルを閉じている間は、「保存」「コピー」をツールバーの右端に表示する。

「詳細設定」と「出力」は見出しをクリックすると開閉できる。閉じていても、見出しの右に現在の設定 (変更している詳細設定の項目・出力形式・自動保存の有無) を表示する。

設定パネル下端の結果欄には、トリミング後のサイズ・元画像に対する面積の増減・元画像のサイズ・トリミング範囲の左上の位置を表示する。設定の変更後、再計算が終わるまではサイズの横に処理中の表示が出る。

## 基本的な流れ

| ステップ | 操作 | 説明 |
| :--- | :--- | :--- |
| **1** | **画像を開く** | 「開く」でファイルを選択、ウィンドウへドラッグ & ドロップ、または「貼り付け」でクリップボードから読み込む (クリップボードの画像のほか、エクスプローラーなどでコピーした画像ファイルも貼り付けられる) |
| **2** | **許容度を調整** | 設定パネルの「許容度」スライダーで背景色の許容範囲を設定する (0: 完全一致に近い、100: 広い範囲を余白とみなす) |
| **3** | **余白を調整** | 設定パネルの「余白」で、トリミング後に追加したい余白ピクセル数を設定する (0〜100 px)。内容から四辺までが常に指定幅になり、元画像の端を越える分は背景色で塗られる。辺ごとの指定は [トリミングの細かい調整](adjust.md#トリミングの細かい調整) を参照 |
| **4** | **結果を出力** | 設定パネル下端の「保存」でファイルへ書き出す、または「コピー」でクリップボードへコピーする。設定変更後のトリミング再計算中は両ボタンが無効になる。保存する形式とファイル名は [保存と一括処理](output.md) を参照 |

スライダーはドラッグ中もプレビューが更新される。スライダーにマウスを乗せた状態で <kbd>←</kbd> <kbd>→</kbd> キーを押すと値を微調整できる。

### プレビューの表示

プレビュー上部の切り替えで、表示を次の 3 つから選ぶ。選んだ表示は次回起動時も保持する。

| 表示 | 説明 |
| :--- | :--- |
| **範囲** (既定) | 元画像を大きく表示し、削られる領域を暗くしてトリミング範囲の枠線を重ねる |
| **結果** | トリミング後の画像だけを表示する |
| **並べて** | 元画像 (左) とトリミング後 (右) を並べて表示する |

透明部分は市松模様で表示する。「結果」の表示中に「スポイト」を押すと、元画像をクリックできるよう「範囲」の表示へ切り替わる。

### ズームとパン

プレビューは各ペイン (元画像・トリミング後) を個別に拡大・縮小できる。倍率と位置は表示を切り替えても保持する。画像がペインより大きいときは、ペインに収まる倍率で表示する。

| 操作 | 説明 |
| :--- | :--- |
| **ホイール** | カーソル位置を中心に拡大・縮小する (最大 1600%)。収まる倍率より小さくはならない |
| **ドラッグ** | 拡大した画像を移動する |
| **フィット** | ペインに収まる倍率へ戻す。ウィンドウサイズの変更にも追従する |
| **100%** | 等倍 (画像 1 px を画面の物理 1 px) で表示する。表示スケールが 125% などの環境でも画素がそろって表示される |

現在の倍率はペインの右下に表示する。新しい画像を開くと、倍率と位置は元に戻る。

## その他の操作

| ボタン | 説明 |
| :--- | :--- |
| クリア (プレビュー右上) | 読み込んだ画像をクリアして初期状態に戻す |
| 設定 | 右側の設定パネルを開閉する |
| ≡ | メニューを開く。次の項目がある |

「≡」メニューの項目は次のとおり。

| 項目 | 説明 |
| :--- | :--- |
| 🌙 ダークテーマ / ☀ ライトテーマ | テーマの切り替え |
| 📖 ドキュメント | このドキュメントを既定のブラウザで開く |
| 📄 ライセンス | このアプリのライセンスをメモ帳で開く |
| 📄 第三者ライセンス | 使用しているオープンソースソフトウェアのライセンスをメモ帳で開く |
| EdgeCut vX.Y.Z | 現在のバージョン (表示のみで押せない) |
| 更新を確認… | 更新ダイアログを開く |

## キーボードショートカット

各ボタンにマウスを乗せたときの表示にも対応するキーを記載している。

| キー | 操作 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | 画像を開く |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | 一括トリミング |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | クリップボードから貼り付け |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | トリミング後の画像を保存 |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | トリミング後の画像をコピー |
| <kbd>Delete</kbd> | 画像をクリア |
| <kbd>Esc</kbd> | スポイトを解除 (スポイト中でなければ一括トリミングを中止) |

## アプリ更新

ツールバー右端の「≡」メニューから現在のバージョンを確認し、更新を適用できる。

1. 「更新を確認…」で更新ダイアログを開き、最新リリースを問い合わせる
2. 新しいバージョンがあれば、現在・最新のバージョンとサイズが表示される。「⬇ ダウンロードしてインストール」でインストーラー (MSI) をダウンロードする
3. サイズ・SHA-256・署名をすべて検証できた場合のみインストーラーを起動し、EdgeCut は終了する (未保存の画像は先に保存しておく)

一括トリミングや保存の実行中は「ダウンロードしてインストール」を押せない。完了してから更新する。ダウンロード中も、一括トリミングと保存は開始できない。

最新版を使用している場合は「再確認」で問い合わせ直せる。確認・ダウンロードにはタイムアウトがあり、失敗時はダイアログの「再試行」でやり直せる。検証に失敗したインストーラーは適用しない。
